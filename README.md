# 남극탐험 🐧

펭귄과 함께 얼음 구멍을 피해 남극점까지 질주하는 달리기 게임입니다. 서버 없이 `index.html` 만 열면 돌아갑니다.

## 조작
- 키보드: `←` `→` 옆으로 피하기, `Space` 점프(시작도 `Space`).
- 폰: 끌어서 이동, 탭하거나 위로 밀어 점프.

## 규칙
- 크레바스와 바다표범은 뛰어넘고, 부딪히면 목숨이 줄고 −100점. 🚩 깃발은 +200점.
- 시간 안에 기지에 닿으면 스테이지 클리어. 최고 점수는 `antarcticBest` 로 저장됩니다.

## 구조
- `index.html` 화면·입력, `logic.js` 규칙.
- 규칙은 DOM 없는 `logic.js`, 시험은 `node --test` (`test/logic.test.js`).
